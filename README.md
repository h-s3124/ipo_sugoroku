# IPO双六「めざせ上場！」プレイ版

SVCO育成講座で使うIPO双六のプレイ版です。サイコロとカードは実物を使い、出た目や引いたカードを画面に入力して進めます。

## 遊び方

- **このPCだけで遊ぶ**：1台のPCを囲んで（プロジェクターに映して）遊ぶ。
- **オンライン：部屋を作る**：ホストのPCが部屋を作ると、4文字の部屋コードが出る。ゲーム中はこのPCのページを閉じない。
- **オンライン：部屋に参加**：ほかのPCは部屋コードを入れて参加し、担当するプレイヤーを選ぶ。自分の担当の番だけ操作できる。

オンライン部屋はPeerJS（WebRTC）でPC同士を直接つなぎます。接続の仲介にPeerJSの公開サーバーを使うため、インターネット接続が必要です。WebRTCを止めているネットワークではつながらないことがあります。

## ファイル

- `index.html`：ゲーム本体（このファイルだけで動く）。PeerJS 1.5.2（MIT License, https://github.com/peers/peerjs ）を同梱。
